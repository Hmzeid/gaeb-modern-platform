Arabic (RTL) — a first-class interface

Arabic is a layout, not a translation: full mirroring, Arabic labels for every workflow status, locale digits for values, Latin preserved for identifiers. Dictionary parity between English and Arabic is enforced by an automated test (249 keys each).

Tablet and mobile

At tablet width the rail and grids adapt; at phone width the rail becomes a top strip and the page never scrolls horizontally (verified programmatically on every major view).

Known limitations, stated plainly: data shown is the synthetic demonstration dataset (7 buildings, 4 governorates) — the same screens were verified against a generated 1,000,000-record registry in the scale report. Screenshots render with system fonts in the build sandbox; on a normal network the product loads Inter / IBM Plex Sans Arabic. Screen-reader validation with NVDA/VoiceOver remains an external gate.

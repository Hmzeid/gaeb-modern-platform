# Phase 14 — Three-Week Pilot Execution Plan (Workstream G)

*Proposed activities after all entry conditions are met — a
plan, not a record. Entry conditions: charter signed ·
BD-07/BD-08 recorded · extract authorization signed · host
qualified · participants named.*

## Week 0 (provisioning, 3–5 days)
Host provisioning per the Infrastructure Mobilization package ·
environment preflight run + report filed · backup taken and
**restore drill executed and filed** · test alert received at
the GAEB destination · accounts issued (administrator via CLI,
then named users) · pilot record created in the platform ·
charter/scope/BD evidence submitted and independently verified.

## Week 1 — Environment & controlled intake
Day 1: activation conditions completed; server activates the
pilot only when all 12 verify. Day 2: first extract received
per protocol; SHA-256 verified at receipt; dataset registered
and authorized (hash pinned). Day 3: standalone preflight
verdict on the extract; controlled import (tracked job, live
progress). Day 4: quarantine review with the data owner;
reconciliation package #1. Day 5: transform under current
authorization; School Map validation begins; pilot board #1.

## Week 2 — Business validation
Reconciliation deep-dive (control totals, duplicate
dispositions under the BD-07 rule) · Arabic fidelity sample
review with GAEB reviewers · historical record spot-validation
against legacy screens · UAT tracks: Tenders, Certificates
(after BD-03/BD-04), Estimates read paths, Real Estate ·
defect triage daily; fixes ship to the pilot environment under
change control; controlled re-runs where a batch requires it.

## Week 3 — Acceptance & closure
Final reconciliation across all pilot batches · outstanding
exceptions decided in writing · UAT retests (failed runs remain
in the record) · performance observations documented from the
pilot host · operational handover (handbook, preflight tool,
backup tooling) · customer acceptance review against the
charter thresholds · pilot closure (or approved extension) in
the platform · production-readiness gap assessment delivered.
